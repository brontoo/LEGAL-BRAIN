# صور الفريق — الصور الخمسة موجودة هنا

المشهد يقرأ الصور من هذا المجلد **تلقائياً**. لا تعديل في الكود.

## الأسماء — حرفياً

| الملف | الشخصية |
|---|---|
| `library.jpg` | أمين المكتبة |
| `drafter.jpg` | مُسوَدَّة أفندي |
| `inspector.jpg` | المفتش ثُغرة |
| `polisher.jpg` | سيبويه المُكشّر |
| `sealer.jpg` | المعلم أبو الختم |

⚠️ **والاسم يجب أن يطابق حرفياً.** واسم خاطئ لا يُنتج خطأً واضحاً — يرجع المشهد
إلى أيقونة الدور بصمت، فتبدو كأنك لم تُضف شيئاً.

## ⚠️ ولماذا `.jpg` لا `.png`

الصور الخمس التي أُنتجت كانت **ملفات JPEG بأسماء `.png`**. والامتداد الكاذب
**ليس تفصيلاً شكلياً**: الخادم يعلن `Content-Type: image/png` والمحتوى JPEG،
ومع ترويسة `X-Content-Type-Options: nosniff` **يرفض المتصفح رسمها**.

فأُعيدت تسميتها إلى `.jpg` الصحيحة. والأحجام صغيرة أصلاً (٨٨–١٤٧ كيلوبايت)،
فلا مكسب في تحويلها إلى PNG — بل خسارة: الصورة الفوتوغرافية تُضخَّم في PNG
إلى ثلاثة أضعاف حجمها.

والكود يجرّب **الامتدادين معاً** بالترتيب: `.jpg` ثم `.png`. فلو وُلِّدت صور
جديدة بصيغة PNG حقيقية، تعمل بلا أي تعديل.

## المواصفات

| البند | القيمة |
|---|---|
الامتداد | `jpg` أو `png` — **ويجب أن يطابق المحتوى الفعلي** |
الأبعاد | **طولية أو مربّعة** — والطولية أفضل لهذا التخطيط. تُعرض بارتفاع ٧٢–٨٤ بكسل |
الحجم | **أقلّ من ٢٠٠ كيلوبايت** للصورة |
الخلفية | **`#0F1525`** — وهو لون المشهد نفسه، فتندمج الصورة بلا إطار · أو خلفية **شفّافة** |
المحتوى | **صدر الشخص فقط، بلا منضدة** — فالمنضدة والشاشة وفنجان القهوة تُرسم فوقها بـ CSS |

> **عن لون الخلفية:** طابقنا خلفية المشهد بـ `#0F1525` لأنها اللون الذي جاءت به
> الصور. والفرق عن `#0F172A` درجتان في الأخضر وخمس في الأزرق — لا تراه العين،
> لكن **حدّ المستطيل** تراه. فالمطابقة أزالت الإطار.

## كيف يعمل

```tsx
// office-scene.tsx
const ART_EXTENSIONS = ["jpg", "png"] as const;
...
<motion.img
  key={artExtension}                          // ← يُجبر طلباً جديداً عند التبديل
  src={`/agents/${worker.key}.${artExtension}`}
  onError={() => setAttempt((n) => n + 1)}    // ← يجرّب التالي، ثم الأيقونة
/>
```

فإن أخطأت في اسم ملف واحد، **تظهر أيقونته وحدها** وبقية الفريق صورهم. وهذا
مقصود: لا يتوقّف المشهد كله بسبب ملف.

## التحقّق السريع

افتح في المتصفح — **بلا حاجة لتشغيل الخادم** (`public/` يُخدَم من القرص):

```
https://<اسم-الكودسبيس>-3000.app.github.dev/agents/library.jpg
```

**ثم بدّل `library` بـ** `drafter` · `inspector` · `polisher` · `sealer`.
