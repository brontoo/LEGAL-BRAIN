# صور الفريق — ضع الصور هنا

المشهد يقرأ الصور من هذا المجلد **تلقائياً**. لا تعديل في الكود.

## الأسماء المطلوبة — حرفياً

| الملف | الشخصية |
|---|---|
| `library.png` | أمين المكتبة |
| `drafter.png` | مُسوَدَّة أفندي |
| `inspector.png` | المفتش ثُغرة |
| `polisher.png` | سيبويه المُكشّر |
| `sealer.png` | المعلم أبو الختم |

⚠️ **والاسم يجب أن يطابق حرفياً.** واسم خاطئ لا يُنتج خطأً واضحاً — يرجع
المشهد إلى أيقونة الدور بصمت، فتبدو كأنك لم تُضف شيئاً.

## المواصفات

| البند | القيمة |
|---|---|
الامتداد | `png` (حرفان صغيران) |
الأبعاد | مربّع · **512×512** كافية (تُعرض بـ ٧٢–٨٤ بكسل) |
الخلفية | **`#0F172A`** — وهو `slate-900`، نفس لون المشهد فتندمج الصورة بلا إطار · أو خلفية **شفّافة** |
المحتوى | **صدر الشخص فقط، بلا منضدة** — فالمنضدة والشاشة وفنجان القهوة تُرسم فوقها بـ CSS |

## كيف يعمل

```tsx
// office-scene.tsx
<motion.img
  src={`/agents/${worker.key}.png`}
  onError={() => setArtFailed(true)}   // ← يرجع للأيقونة إن لم يجد الملف
/>
```

فإن أخطأت في اسم ملف واحد، **تظهر أيقونته وحدها** وبقية الفريق صورهم. وهذا
مقصود: لا يتوقّف المشهد كله بسبب ملف.

> **قبل إضافة الصور** تظهر أخطاء `404` لهذه الملفات الخمسة في طرفية المتصفح.
> وهي متوقّعة ولا تعني خللاً — وهي تختفي بمجرد إضافة الملفات.

## إن كانت صورك في ورقة واحدة

ولّدتَ التسلسل في صورة واحدة كبيرة؟ **اقتطع كل خانة** واحفظها باسمها. ويكفي أي
محرّر صور، أو أرسل الورقة وأقتطعها لك.

الموجّهات وكل التفاصيل في [`../../../agent-art-prompts.md`](../../../agent-art-prompts.md).
