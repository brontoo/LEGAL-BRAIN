# ⚖️ LEGAL-BRAIN — العقل القانوني الإماراتي

منصة عربية أولاً (Arabic-first) لتوليد المستندات القانونية الإماراتية **بأسلوب المحامي نفسه**.

الفكرة ليست الإجابة عن أسئلة قانونية عامة، بل استرجاع **سوابق المستخدم الشخصية** — عقوده،
إنذاراته، لوائحه، وكالاته، تشريعاته — ثم صياغة مستند جديد بنفس نبرته وهيكله ومفرداته.

---

## ما الذي يفعله النظام

| العائلة المستندية | المصدر | جدول قاعدة المعرفة |
|---|---|---|
| تشريعات وأحكام | HTML من موقع التشريعات + PDF ممسوح (OCR) | `legal_documents` |
| مذكرات ولوائح | PDF / DOCX | `legal_drafts` |
| عقود واتفاقيات | PDF / DOCX | `legal_contracts` |
| إنذارات | PDF / DOCX | `legal_notices` |
| وكالات | PDF / DOCX | `legal_poa` |

يُقطَّع كل مستند إلى وحدات دلالية (مادة / بند / قسم / صلاحية)، تُحوَّل إلى متجهات
بعدد 1024 بُعداً بنموذج `intfloat/multilingual-e5-large`، وتُخزَّن في Supabase
(PostgreSQL + pgvector). ثم يسترجع وكيل LangGraph السوابق الأقرب دلالياً ويصوغ
المستند الجديد.

## المتطلبات

| المكوّن | الإصدار |
|---|---|
| Python | 3.11+ (طُوِّر على 3.14) |
| Node.js | 20.19+ أو 22.12+ (اختُبر على 24) |
| PostgreSQL | مع امتداد `vector` (Supabase يوفّره) |

**حزم نظام مطلوبة لمسار الـ OCR** (ليست حزم pip):

```bash
# Ubuntu / Debian
sudo apt install tesseract-ocr tesseract-ocr-ara poppler-utils

# macOS
brew install tesseract tesseract-lang poppler
```

للتحقق: `tesseract --list-langs` يجب أن تُظهر `ara`، و`pdftoppm -v` يجب أن يعمل.

## التثبيت

```bash
# ٠. ⚠️ على Linux / Codespaces: ثبّت torch نسخة CPU أولاً
#    بدونه يسحب torch حزمة CUDA بحجم 2.74 GB لا فائدة منها بلا GPU،
#    فيفشل التثبيت بـ "No space left on device".
pip install torch --index-url https://download.pytorch.org/whl/cpu

# ١. اعتماديات بايثون — تكفي لتشغيل الخادم وخطوط الاستيعاب
pip install -r requirements.txt

# ١-ب. اختياري: واجهة Chainlit + مزوّد Groq البديل
#      (لا يحتاجها main.py — تُثبَّت عند الحاجة إليها فقط)
pip install -r requirements-optional.txt

# ٢. متغيّرات البيئة
cp .env.example .env          # ثم املأ المفاتيح الفعلية

# ٣. اعتماد Google (للاستيعاب فقط، لا يلزم لتشغيل الخادم)
#    ضع ملف مفتاح حساب الخدمة باسم credentials.json في جذر المشروع

# ٤. بناء قاعدة المعرفة — نفّذ محتوى schema.sql داخل Supabase SQL Editor

# ٥. واجهة Next.js
cd frontend
cp .env.local.example .env.local
npm install
```

> **ملاحظة:** أول تشغيل يحمّل نموذج التضمين `intfloat/multilingual-e5-large` (~2.2 GB).


## متغيّرات البيئة

### الخادم (`.env`)

| المتغيّر | إلزامي | الوصف |
|---|---|---|
| `SUPABASE_URL` | ✅ | عنوان مشروع Supabase |
| `SUPABASE_KEY` | ✅ | مفتاح API — يُستخدم للكتابة والبحث |
| `GOOGLE_API_KEY` | ✅ | مفتاح Gemini (الوكيل الأساسي) |
| `API_TOKEN` | ⚠️ للنشر | رمز مصادقة الـ API. بدونه `/generate` و`/chat` مفتوحان لأي زائر |
| `GROQ_API_KEY` | ❌ | مطلوب فقط لـ `ask_brain.py` و `test_groq.py` |
| `ALLOWED_ORIGINS` | ❌ | نطاقات CORS — **لم تعد الواجهة تحتاجها** (انظر أدناه) |
| `MAX_HISTORY_TURNS` | ❌ | أدوار المحادثة المحفوظة لكل جلسة (افتراضي 6) |
| `PORT` | ❌ | منفذ `python main.py` (افتراضي 8000) |
| `DRIVE_FOLDER_*` | ❌ | تجاوز معرّف مجلد Drive بلا لمس `drive_folders.py` |

### الواجهة (`frontend/.env.local`)

| المتغيّر | الوصف |
|---|---|
| `BACKEND_URL` | عنوان FastAPI **كما يراه خادم Next.js** (افتراضي `http://127.0.0.1:8000`) |
| `API_TOKEN` | **نفس** قيمة الرمز في `.env` بالجذر |

> ⚠️ **لا بادئة `NEXT_PUBLIC_` في أيٍّ منهما، وهذا مقصود.**
> الواجهة لا تخاطب FastAPI مباشرة، بل تمرّ عبر الوسيط
> `frontend/app/api/[...path]/route.ts` الذي يضيف رمز المصادقة **من جهة الخادم**.
> ولو وُضع الرمز في متغيّر `NEXT_PUBLIC_` لكُشف في جافاسكربت المتصفح
> وأصبحت المصادقة بلا معنى.
>
> ونتيجة لذلك: **لا حاجة إلى CORS إطلاقاً** (المتصفح يخاطب نفس الأصل)،
> و**لا حاجة لجعل المنفذ 8000 عاماً** (الوصول كله من جهة الخادم).

## الاختبارات

```bash
cd legal-brain
python -m unittest discover -s tests -t . -v
```

> ⚠️ **لا تشغّل `python -m unittest discover` بلا معاملات من الجذر.**
> الاكتشاف الافتراضي يلتقط `test_groq.py` في الجذر — وهو يحتاج مفتاح Groq
> وشبكة، فيفشل ويسقط معه الاختبار كله. تحديد `-s tests` يحصره في مجلده.

### ما الذي يُختبر

| الملف | ما يغطّيه |
|---|---|
| `tests/test_citations.py` | تطبيع النصّ العربي · مطابقة الاقتباس · قراءة كتلة الأسانيد · الحكم على الاستشهادات · فحص أرقام المواد |

**٦٥ اختباراً تعمل في أقل من عُشر ثانية** — بلا شبكة، وبلا مفتاح API، وبلا
نموذج تضمين، وبلا قاعدة بيانات.

السبب عملي لا أكاديمي: **الاختبار الذي يحتاج شبكة أو رصيداً لن يُشغَّل**، ومجموعة
اختبارات لا تُشغَّل أسوأ من عدمها لأنها تُوهم بالأمان. ولذلك كل ما يُختبر هنا
دوالّ نقية. أما ما يحتاج نموذجاً — جودة الصياغة ومطابقة أسلوب المحامي — فمحلّه
اختبارات منفصلة تُشغَّل يدوياً عند الطلب.

## عقد الاستشهاد — `citations.py`

**المشكلة:** الوكيل يكتب المسودّة، ولا شيء يتحقّق أن ما فيها من مواد موجود فعلاً
في أرشيفك. فمادة مؤلَّفة تمرّ صامتة إلى مستند يُسلَّم.

**الحلّ:** النموذج **يروي**، والخادم **يُقرّر**.

1. كل مقطع مسترجع يحمل مرجعاً قصيراً (`L1` للتشريعات · `C2` للعقود · `N1` للإنذارات).
2. يُطلب من النموذج أن يُرفق **اقتباساً حرفياً** لكل سند — لا رقم مادة.
3. `citations.py` **يتحقّق حتمياً** أن كل اقتباس موجود حرفياً في نصّ المقطع
   الذي رآه النموذج.
4. ويفحص كل رقم مادة في المتن: ما لم يظهر في أي مقطع مسترجع = **بلا سند**.

**الفائدة:** مادة مؤلَّفة لا تستطيع إنتاج اقتباس حرفي موجود في أرشيفك.

صيغة الكتلة التي يُرفقها النموذج في آخر المستند:

```
[[الأسانيد]]
L1 :: الغرامة سبعون درهماً عن كل يوم تأخير
C2 :: مدة الإخطار ثلاثون يوماً
[[/الأسانيد]]
```

ويُحذف هذه الكتلة `strip_citations_block()` قبل النسخ إلى Word، فلا يظهر في
المستند النهائي إلا المتن.

> **⚠️ حدود الفحص بصراحة:** التحقّق يمنع **التأليف**، ولا يمنع **سوء التطبيق**.
> فمادة موجودة في الأرشيف قد تكون غير منطبقة على الواقعة — وهذا حكم قانوني لا
> يحسمه كود. الفحص يجعل الأسانيد مرئية وقابلة للتتبّع، والقرار يبقى للمحامي.

## حلّ المشكلات

| العرض | السبب المرجّح |
|---|---|
| الخادم لا يبدأ / `create_client` يفشل | `.env` ناقص أو غير مُحمَّل |
| «لا توجد نصوص مطابقة» دائماً | سكربتات الاستيعاب لم تُشغَّل، أو `schema.sql` لم يُنفَّذ |
| `match_legal_* does not exist` | لم تُنفَّذ دوال الـ RPC في `schema.sql` |
| الواجهة تبقى في شاشة التحميل | تأكد أن الخادم يعمل؛ والوسيط يعرض عنوانه الحقيقي في رسالة الخطأ |
| الواجهة تقول «تعذّر الوصول إلى خادم FastAPI» | الخادم متوقف — شغّل `./dev.sh` |
| `401 مصادقة مطلوبة` | ضبطتَ `API_TOKEN` في `.env` ولم تنسخه إلى `frontend/.env.local` |
| خطأ CORS في المتصفح | أضف عنوان الواجهة إلى `ALLOWED_ORIGINS` في `.env` |
| `tesseract` يفشل | حزمة اللغة العربية `ara` غير مثبَّتة |
| OCR ينتج نصاً مشوّهاً | ملف PDF صوري بجودة منخفضة، أو حزمة `ara` مفقودة |

## الفجوات المعروفة

**أُصلحت مؤخراً:**
- ✅ **معرّفات مجلدات Drive** انتقلت إلى `drive_folders.py` — مصدر واحد بدل سبعة
  ملفات، مع إمكانية التجاوز من متغيّرات البيئة (`DRIVE_FOLDER_*`).
- ✅ **`ingest_documents.py`** — استُبدل `flow.run_console()` المُزال من
  `google-auth-oauthlib` 1.x بـ `run_local_server`، وأُضيف فحص منع التكرار
  الذي كان **غائباً فيه وحده** (كان تشغيله مرتين يُضاعف كل التشريعات).
- ✅ **التحميل الثقيل عند الاستيراد** — `legal_agent.py` صار يُهيّئ النموذج
  واتصال Supabase **عند أول استخدام** بدل الاستيراد، مع رسالة واضحة عند نقص
  متغيّرات البيئة. إقلاع الخادم لم يعد ينتظر تحميل 2.2 GB.
- ✅ **تسريب المفتاح** في `smart_office.py` — أُزيل طبع أول 10 أحرف من مفتاح
  Gemini، وصار فحص وجوده **قبل** استخدامه (كان ينهار بـ `TypeError`).
- ✅ `server.py` حُذف (نسخة مكررة حرفياً من `main.py`).
- ✅ **مصادقة الـ API** — `/generate` و`/chat` يُلزمان بـ `API_TOKEN` عند
  ضبطه، والواجهة ترسله من جهة الخادم عبر وسيط Next.js.
- ✅ **أول شبكة اختبارات** — `tests/` بـ ٦٥ اختباراً حتمياً تعمل بلا شبكة
  ولا رصيد. وسيُضاف إليها ما يلزم مع كل تغيير.

**لا تزال قائمة:**

- **التغطية الاختبارية جزئية** — `citations.py` مُختبَر بالكامل، لكن
  `legal_agent.py` و`main.py` وبقية السكربتات بلا اختبارات بعد.
- **`citations.py` غير مربوط بعد** — الوحدة مبنية ومُختبرة، لكن الأدوات
  الخمس لا تُسجّل أدلّتها ولا تُرقّم مراجعها، وعقدة التحقّق ليست في المسار.
- **بيانات الواجهة وهمية** في لوحة القيادة والمكتبة (لا تتصل بالـ backend بعد)،
  واللوحة تذكر «Qdrant» بينما المخزن الفعلي هو Supabase/pgvector.
- **`Select`** مبني ولم يُستخدم؛ `InputGroup` صار مستخدماً في صفحة المكتبة.
- **`legal_contracts`** قد يحوي مقاطع مكرّرة من تشغيلات سابقة (قبل إصلاح فحص
  منع التكرار).

## ⚠️ الأمان

`.env` و`credentials.json` و`token.pickle` مُستثناة من git — لا ترفعها أبداً.
إن كانت `SUPABASE_KEY` هي `service_role` فهي تتجاوز RLS وتملك صلاحية كاملة على القاعدة:
لا تضعها في أي متغيّر يبدأ بـ `NEXT_PUBLIC_` ولا تُرسلها إلى المتصفح.

### قبل أي نشر عام — ثلاثة أمور إلزامية

1. **اضبط `API_TOKEN`.** بدونه `/generate` و`/chat` مفتوحان لأي زائر: يستخدم
   أرشيفك القانوني ويستهلك رصيد Gemini على حسابك. التحقق: `GET /health` يُظهر
   `"auth_required": true`.
2. **فعّل RLS** على جداول Supabase — القسم ٨ في `schema.sql` جاهز.
3. **دوّر المفاتيح** إن كانت قد ظهرت في أي لقطة شاشة أو سجل أو محادثة.

> **لماذا لا يكفي رمز في الواجهة؟** لأن أي متغيّر يبدأ بـ `NEXT_PUBLIC_`
> يُحزَّم داخل جافاسكربت المتصفح، فيقرأه أي زائر من مصدر الصفحة. ولذلك يرسل
> الوسيط `frontend/app/api/[...path]/route.ts` الرمز من جهة الخادم فقط.
